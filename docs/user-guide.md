## 一、产品简介

**秋招画像**是一款面向中国应届生（本科/硕士/博士）的秋招全流程管理工具。它不依赖后端服务器，所有数据存储在浏览器本地，打开网页即可使用，真正做到了"零注册、零上传、零隐私风险"。

产品围绕秋招的五个核心环节设计：

1. **信息填写** — 建立 87 字段完整个人档案
2. **岗位匹配** — 六维加权引擎自动推荐合适岗位
3. **意向岗位** — 三档经历分析 + STAR 文案生成
4. **简历生成** — 一键整合多格式简历，ATS 兼容
5. **网申自动填充** — Chrome 插件一键填写各公司网申表单

## 二、快速开始（5 分钟上手）

### Step 1：打开网站

访问主站：https://recuritment-portrait.top

无需注册账号，无需登录。首次打开是一个空白档案，所有数据保存在你的浏览器中。

### Step 2：填写基础档案

点击导航栏的「信息填写」，按步骤完成以下必填项：

- **基础信息**：姓名、性别、手机号、邮箱、政治面貌
- **教育背景**：本科/研究生院校、专业、GPA、排名
- **职业意向**：目标岗位方向、目标城市、年薪底线

> 💡 建议：即使某些字段不确定，也先填一个大概值。后续随时可以修改，系统会根据你填的内容动态调整其他页面的推荐策略。

### Step 3：查看岗位匹配

点击「岗位匹配」，系统会根据你的档案自动计算六维匹配度（技术栈、城市、薪资、学历、方向、缺口），并按匹配度从高到低排列。

你可以：
- 标记「已投递」或「不感兴趣」
- 点击任意岗位查看详细的缺口分析和补建议

### Step 4：生成简历

点击「简历生成」，选择你要投递的岗位方向（互联网大厂 / 央国企 / 事业单位），系统会自动：

- 提取最相关的实习和项目经历
- 按 STAR 法则格式化
- 生成 ATS 友好的纯文本版本
- 提供 Word/PDF 排版建议

### Step 5：安装网申插件（可选但强烈推荐）

如果你经常填网申表单，安装 Chrome 插件可以节省大量时间：

1. 下载本项目源码（或从 Release 下载 extension.zip）
2. 打开 Chrome → `chrome://extensions` → 开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择 `extension/` 文件夹
4. 打开任意网申页面，点击插件图标 → 「一键填充」

## 三、各页面详细说明

### 3.1 信息填写（index.html）

这是整个系统的数据入口。共 5 个步骤，覆盖 87 个字段：

| 步骤 | 内容 | 关键字段 |
|------|------|----------|
| 第 1 步 | 基础信息 | 姓名、性别、手机号、邮箱、政治面貌、籍贯 |
| 第 2 步 | 教育背景 | 本科/研究生院校、专业、GPA、排名、导师、论文 |
| 第 3 步 | 职业意向 | 目标岗位、目标城市、年薪底线、一票否决项 |
| 第 4 步 | 经历与能力 | 实习经历、项目经历、技能清单、荣誉奖励 |
| 第 5 步 | 其他信息 | 学生工作、家庭情况、自我评价 |

**操作技巧：**
- 每步填写后点击「保存」，数据自动存入浏览器
- 左下角显示「已暂存」时间戳，确认保存成功
- 右上角「导出 JSON」可备份档案到本地
- 「导入 JSON」可从备份恢复，或从其他设备迁移

### 3.2 岗位匹配（match.html）

系统内置了互联网大厂和央国企的典型 JD 库，覆盖技术、产品、运营、数据分析等方向。

**匹配维度：**
1. **技术栈匹配度** — 你的技能与 JD 要求的重合度
2. **城市匹配度** — 目标城市是否一致
3. **薪资匹配度** — 你的期望是否在岗位预算范围内
4. **学历匹配度** — 本硕博与岗位门槛的匹配
5. **方向匹配度** — 细分方向（如后端/前端/算法）的吻合度
6. **缺口分析** — 你缺少但 JD 要求的能力项

**操作建议：**
- 匹配度 80% 以上的岗位建议优先投递
- 60%-80% 的岗位可以投递但需针对性准备
- 低于 60% 的岗位不建议浪费精力

### 3.3 意向岗位分析（intention.html）

针对你标记为「意向」的岗位，系统会生成个性化的面试准备材料：

- **三档经历分析**：将实习/项目按与岗位的匹配度分为核心档、支撑档、弱相关档
- **STAR 文案生成**：为每个核心经历自动生成 STAR 格式的面试回答文案
- **可深挖点提示**：列出面试官可能追问的技术/业务细节
- **短板预警**：标出你讲不清楚的地方，提醒提前准备

### 3.4 简历生成（resume.html）

**使用流程：**

1. 选择投递对象类型（互联网大厂 / 央国企 / 事业单位）
2. 选择具体岗位方向（如「后端开发」「产品经理」）
3. 系统按以下规则自动筛选内容：
   - 互联网：突出技术深度和量化成果
   - 央国企：突出学生工作、政治面貌、稳定性
   - 事业单位：突出科研成果和公共服务经历
4. 生成后可直接复制纯文本版本到网申系统
5. 如需精美排版，可复制内容到 Word 模板中微调

### 3.5 网申自动填充插件

**核心功能：**
- 基于你的档案，自动识别网申页面的表单字段
- 支持文本框、下拉选择、单选、日期、复选框等多种控件
- 适配 Ant Design、Element UI、Layui 等常见组件库
- 预览模式：先展示匹配结果，确认后再填充

**安全设计：**
- 仅申请 `activeTab`、`scripting`、`storage` 三个最小权限
- 所有数据处理在本地完成，零网络请求
- 高风险 checkbox（如「同意隐私条款」「接受调剂」）不自动勾选，需人工确认

**自定义映射：**
如果某个网申系统的字段名特殊（如「应聘人真实姓名」），内置规则匹配失败，你可以在插件面板中添加自定义映射：「应聘人真实姓名」→「姓名」。自定义规则优先级最高，会覆盖内置规则。

## 四、数据管理

### 4.1 数据存储位置

所有数据存储在浏览器的 `localStorage` 中，key 为 `qiuzhao_profile_v4`。这意味着：
- ✅ 不依赖网络，离线可用
- ✅ 数据完全由你控制
- ⚠️ 清除浏览器数据会丢失档案（务必定期导出备份）
- ⚠️ 不同浏览器之间的数据不互通

### 4.2 导出与备份

**手动导出：**
点击任意页面右上角的「导出 JSON」按钮，下载 `.json` 文件到本地。

**自动备份建议：**
建议每次大幅更新档案后（如新增一段实习、修改职业意向）都导出一次备份。文件名格式：`秋招档案_姓名_日期.json`。

### 4.3 跨设备迁移

在设备 A 上导出 JSON → 通过微信/邮件/U 盘传到设备 B → 在设备 B 上点击「导入 JSON」选择文件即可。

**注意：** 导入会覆盖当前设备的档案。如果设备 B 上已有数据，建议先导出备份再导入。

### 4.4 敏感字段处理

以下字段被标记为敏感，导出时会被隔离到 `_sensitive` 对象中：
- 身份证号
- 家庭成员信息
- 紧急联系人

分享档案给他人前（如导师帮忙改简历），建议先删除 `_sensitive` 部分。

## 五、常见问题（FAQ）

**Q1：我的数据安全吗？会不会被上传到服务器？**

完全不会。秋招画像是纯静态站点，没有后端服务器。所有数据只存在于你的浏览器 `localStorage` 中，甚至连我们（开发者）都看不到你的数据。

**Q2：换了电脑/浏览器，数据还在吗？**

不在。`localStorage` 是浏览器级别的存储，换设备或换浏览器数据会丢失。解决方案：定期导出 JSON 备份，新设备上导入即可。

**Q3：插件安装后为什么显示「无法加载」？**

可能的原因：
- 你的 Chrome 被企业策略管理，禁止加载未打包扩展。可以换用 Edge 浏览器（同样基于 Chromium，支持相同格式的扩展）
- 没有选择正确的文件夹。注意选择的是 `extension/` 文件夹本身，不是里面的某个文件

**Q4：网申插件支持哪些网站？**

理论上支持所有使用标准 HTML 表单或常见组件库（AntD/Element UI/Layui）的网申系统。但以下情况可能无法正常工作：
- 使用自研非标准组件的网申系统（如部分银行的定制系统）
- 带有强反自动化机制的高端网申平台
- 需要验证码或人机验证的页面

**Q5：插件填充错误怎么办？有没有撤销？**

目前版本没有撤销功能。建议：
- 首次使用某个网申系统时，先用「预览匹配结果」模式检查匹配是否准确
- 对于不确定的字段，在预览中取消勾选
- 高风险 checkbox（如隐私条款）插件会自动跳过，不会误操作

**Q6：可以多人共用一套档案吗？**

可以但不建议。每个人的经历、意向都不同，共用会导致匹配和推荐不准确。如果确实需要（如宿舍共享电脑），建议每个人使用不同的浏览器或浏览器用户配置文件。

**Q7：发现 bug 或有功能建议，怎么反馈？**

请通过 GitHub Issues 反馈：https://github.com/yub369302-cyber/Recuritment-Portrait/issues

## 六、高级技巧

### 6.1 利用 URL 参数快速演示

在任意页面 URL 后加 `?demo=1`，可以加载内置的演示数据，快速体验全部功能。演示数据不会保存到本地。

### 6.2 自定义 JD 库

如果你关注的岗位不在内置 JD 库中，可以编辑 `jobs/jd-library.json` 文件，按相同格式添加新的岗位描述，然后刷新页面即可生效。

### 6.3 隐私模式使用

如果你不想在浏览器中留下任何痕迹，可以：
1. 打开浏览器的隐私/无痕窗口
2. 访问网站并填写档案
3. 使用完毕后关闭窗口，数据自动清除
