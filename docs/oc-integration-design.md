# GiveMeOC 集成与数据质量说明

最后复核：2026-10-24

## 当前架构

应用是静态 HTML、Vue 和 ES modules。岗位匹配、意向岗位和简历页面通过 src/job-library.js 加载岗位库：内置精选库必需；本地增强库可选；相同 ID 时增强库覆盖内置记录。岗位详情、匹配分和投递入口均在浏览器本地处理。

## 两类岗位数据

内置 jobs/jd-library.json 保存逐岗职责和关键词，适用于匹配、经历分析和文案挖掘。

GiveMeOC 来源表的“岗位”列是公司级职位名称清单，不是逐岗 JD。转换器把顿号、逗号、分号和换行分隔的职位片段单独分类，不按斜杠拆分；保留来源片段、公司类别、地点、批次、截止日期、入口和更新时间，不推测职责或关键词。相同公司、岗位、方向、批次、官方入口及截止日期的记录合并地点；投递入口或截止日期不同则作为不同线索保留。

缺少岗位方向、地点、批次、公司类别、职责或关键词时，相关评分维度会标成未评估。总分按可用维度重新归一化，并显示覆盖率。企业类别未知时不默认视为互联网公司。没有职责和关键词的职位线索不产生技能缺口，也不能开启经历挖掘。

## 本地转换

依赖在 requirements.txt 中声明。公开仓库不包含源工作簿、补充表或抓取缓存；把本地工作簿放在 `pipeline/givemeoc校招汇总.xlsx` 后，可从项目根目录运行：

    python3 -m pip install -r requirements.txt
    python3 jobs/oc2jd.py --output jobs/jd-library-givemeoc.json

转换器会优先查找仓库内 pipeline/ 下的工作簿，也会兼容原始交付包中与应用目录同级的 pipeline/；支持通过 --input、--output 指定其他路径。它只读工作簿，不联网。源表和生成库被 .gitignore 忽略。

pipeline/update_givemeoc.py 是另一个可选脚本，会访问网站并原位更新 Excel。它支持 --xlsx、--cache 和 --enrichment 指定本地文件。除非明确想要在线抓取和更新工作簿，否则不要运行它。

## 数据现状与限制

项目随附的工作簿中更新时间字段最新到 2026-10-22。现有被忽略的增强库是旧生成物，包含 1,167 条记录，lastUpdate 为 2026-10-22；它没有 responsibilities 和 keywords，当前应用会将其视为职位线索并显示有限覆盖率。本轮没有覆盖工作簿或增强库。

以当前工作簿和 2026-10-24 为截止过滤日期做的一次临时转换预览得到 1,526 条线索：数据分析 430、产品经理 674、商业分析 422。预览文件位于工作区临时目录，没有替换项目中的旧生成物。

截止日期、公司类别和投递入口取自来源表，可能过期或不完整，投递前应以招聘单位的当前公告为准。当前目录不包含任何自动化调度配置，无法据此确认外部定时任务是否仍在注册或运行。

## 隐私与发布

用户档案存于浏览器 localStorage；应用不对其加密，同一源的页面脚本可读取。用户导出的档案和本地投递数据应保留在可信浏览器和设备中。

jobs 下的增强 JSON、源工作簿、补充表和抓取缓存均由 .gitignore 排除。原始交付包把 pipeline 目录放在 Recuritment-Portrait 的同级目录；公开仓库只纳入该目录的脚本和测试。发布前应核对实际部署文件，不要把个人档案、缓存、源工作簿或本地增强库公开。

项目文件没有记录数据源的再利用条款核实结果。是否允许继续存储、派生或分发数据，需要负责人依照来源当前条款确认；本说明不构成授权判断。
