# JD 库扩展指南

本目录存放岗位数据文件 `jd-library.json`，匹配引擎会自动读取并基于用户画像进行打分排序。

## 快速追加岗位（无需改代码）

如果你只是在**现有方向**（数据分析 / 商业分析 / 产品经理）内增加更多公司的 JD：

1. 打开 `jd-library.json`
2. 在 `jobs` 数组末尾追加新的岗位对象
3. 刷新 `match.html` 页面即可看到新岗位

### 最小可用字段

```json
{
  "id": "唯一编号（建议字母+数字，如 X12345A）",
  "company": "公司名（如 字节跳动）",
  "title": "岗位标题",
  "track": "方向，必须是已有方向之一：数据分析 / 商业分析 / 产品经理",
  "employmentType": "正式 / 实习 / 日常实习",
  "program": "2027届校园招聘 / 日常实习 / 2026年度校园招聘",
  "locations": ["北京", "上海"],
  "business": "业务线名称（如 抖音电商）",
  "url": "官方招聘链接",
  "responsibilities": ["职责1", "职责2"],
  "keywords": ["数据分析", "指标体系", "A/B实验"],
  "crawlDate": "2026-08-19"
}
```

只有 `id`、`company`、`title`、`track` 是**必填**的；其余字段缺失时匹配引擎会走中性评分，不会报错。

## 新增方向（需要改 3-4 处）

如果你想支持一个全新的方向（如"算法工程师"），需要同步更新以下映射表：

### 1. 本文件：确认 track 字段使用新方向名

在 `jd-library.json` 中把新岗位的 `track` 设为 `"算法工程师"`。

### 2. `src/match-engine.js`：轨道注册表

找到 `TRACK_REGISTRY`，在 `directionMap` 和 `roleMap` 中各加一行：

```js
directionMap: {
  // ... 已有映射
  '算法工程师': '算法工程师',
},
roleMap: {
  // ... 已有映射
  '算法工程师': '算法工程师',
},
```

`directionMap` 的键是 `schema.js` 中求职意向的下拉选项值；如果用户不需要在填写页选择这个方向，可以只加 `roleMap`。

### 3. `src/schema.js`（可选）：让用户能选这个新方向

在求职意向的下拉选项数组中追加 `"算法工程师"`。

### 4. `src/portrait-engine.js`（可选）：让画像能识别这个角色

在 `ROLE_TEMPLATES` 中追加算法工程师的雷达图权重模板。如果不加，画像引擎不会输出"算法工程师"角色，但岗位仍然可以正常匹配（只是拿不到 +5 分加成）。

## 新增公司

直接在 `jobs` 数组中追加即可，**无需改任何代码**。不在 `COMPANY_TYPE` 映射表中的公司会走中性企业评分。

## 新增城市

直接在 `locations` 中写城市名即可。如果城市名比较特殊（如"广东深圳市"这种脏数据），建议把纯净城市名追加到 `src/match-engine.js` 的 `KNOWN_CITIES` 数组里，地点归一化会更准确。

## 数据规范

- `id` 必须全库唯一，重复会导致覆盖或不可预期行为
- `keywords` 是业务能力词（如"增长""指标体系"），不是工具名（如"SQL""Python"）。工具匹配由技能表自动处理
- `responsibilities` 文本会参与技能印证，写清楚有助于提高匹配精度
